What it does

  • 01Light coding

    Small fixes and scripts, tested as it goes. Not built for large projects.

    file_read·file_edit·bash

  • 02Research

    Reads sources and saves a report with links.

    search_web·browse_web·file_write

  • 03Schedules

    Runs a prompt on a timer and notifies you.

    schedule_job·0 7 * * 1-5

  • 04Memory

    Saves what it learns as Markdown you can edit.

    remember·recall·data/memories/

  • 05Skills

    Markdown how-tos. It proposes fixes you can review and undo.

    data/skills/<name>/SKILL.md

  • 06Helpers & tools

    Parallel helper agents, MCP servers, a browser, a REST API.

    spawn_worker·await_workers·mcp_add_server

Get started

  1. 01

    Use a VM, container or spare machine with Python 3.11+.

  2. 02

    Pick a model: Ollama, OpenRouter, OpenAI or any compatible server.

  3. 03

    Run the commands, open localhost:8090, then Settings → Providers & models.

This is experimental host-executing software. Pernix can run shell commands, write files, and make network requests. Back up important data, give it a contained environment, and do not expose it directly to the public internet. Prompt rules and tool approval gates are not a security sandbox. Read the security model.
